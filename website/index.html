One language.
The whole display stack.

Most desktops are assembled from borrowed parts. Insane OS went the other way: a Wayland compositor, an interface engine, a terminal — all written in C11 from zero, on top of nothing but libc, libxkbcommon and libwayland. Vendored QuickJS for the interface, and that is the entire inheritance.

A living galaxy, not a picture

The wallpaper is a video, decoded in hardware through VA-API. It pauses when the battery is low, when a window covers it, when the CPU is busy — and resumes the moment you look at it again.

Widgets that wear the wallpaper's colours

The clock and the system meters sample the playing wallpaper and re-ink themselves to match its palette. The desktop always agrees with itself.

Permissions like a phone

An app that wants your camera, microphone, files or network asks first — and the firewall shows every connection on a live map. Deny anything, per app.

A system that naps

Forty-eight seconds of heavy use and the freezer quietly stops background apps. Open them again and they're exactly where you left them.

Screenshots that read

Capture the screen, a window, or an area — then press T and the text inside the picture is yours. OCR runs in a sealed sandbox, offline.

Passwords, a vault, and a apple of code

2FA, autofill, per-app keyring isolation, signed packages, and verified system code — the boot loader checks the hash of everything it runs.

From download to desktop

  1. Download the image

    One ISO, about 2 GB. Signed; the signature is checked by the installer itself.

  2. Flash a USB stick

    Any 4 GB stick works. dd, Rufus, balena Etcher — whatever you already trust.

  3. Boot and choose

    Try it live without installing anything, or go straight to the installer. Full-disk encryption (LUKS) is a checkbox, not a ritual.

  4. Answer four questions

    Name, password, timezone, keyboard. The installer is the same one the live system runs, so you've already seen it work.

  5. First boot

    The burst, the particles, the login — and a desktop that greets you with the tour if you want it.

What it needs

Any 64-bit x86 PC from the last decade. 4 GB of RAM for the live system, 20 GB of disk for an install. Intel, AMD and Raspberry Pi 5 graphics are handled by the compositor's own GPU path — and if there is no GPU, it paints on the CPU and stays smooth anyway.

Privacy policy

Short version: Insane OS is your computer being your computer. There is no account, no telemetry, and no server to send anything to.

No telemetry.
The system keeps no usage statistics and makes no analytics requests. There is no crash-report uploader: crash logs stay in your home folder until you delete them.
Per-app permissions.
Camera, microphone, files and network are gated per app. An app asks, you answer, and the answer is stored in a plain file you can read: ~/.config/insaneos/permisos.json.
A firewall you can watch.
Every connection is shown live — app, address, country — and can be allowed or blocked by app, domain or network. Rules are enforced by the kernel's packet filter.
Verified system code.
The boot process checks an Ed25519-signed manifest and the SHA-256 hash of every piece of system code before running it.
Sandboxed helpers.
Media, documents, OCR and passwords run in confined helpers: no network, no sockets, no exec, Landlock and seccomp enforced, each seeing only the one file it was given.
Your secrets stay sealed.
Passwords and 2FA live in a vault locked with your password or a USB key, on memory that is wiped on every way out.
Open by construction.
The whole system is built from public source. This site's claims are checkable in the tree, not taken on faith.

Insane OS — free software, GPL, built on Debian. Made by one person who wanted a desktop they could read to the end.
